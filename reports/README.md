## Interpretation rule

Results are labelled by what the experiment supports:

- **measured** — directly extracted from the stated data;
- **demonstrated interval** — performance over a stated window/configuration;
- **interpretation** — a data-supported explanation that is not a unique causal proof;
- **proposed / in fabrication** — engineering work that still requires validation.

As of 6 October 2026, V25 is in fabrication. It is not yet a measured performance result.
