# EXOhSPEC research-record archive

**Author and curator:** Biswajit Jana  
**Supervisors:** Prof Hugh R. A. Jones and Prof Bill Martin  
**Archive assembled:** 6 October 2026

This directory provides the historical evidence base for the EXOhSPEC scientific website and the CLFCD research track. It combines relevant PDF reports recovered from the research working archive with PDF attachments from sent project email.

## Contents

- pdf-reports/email-sent/ — original PDF attachments recovered from relevant sent messages.
- pdf-reports/downloads-reviewed/ — relevant local PDFs retained in the original archive snapshot.
- pdf-inventory.json — page count, byte size, SHA-256, research classification, first-page text preview and duplicate count.
- email-sent-index.json — minimal message provenance: date, subject, recipients, attachment name and Gmail message ID.
- [A-Z-RESEARCH-STORY.md](A-Z-RESEARCH-STORY.md) — current chronological interpretation of the programme.

## Important scope note

The PDF inventory is a dated archive snapshot, not an assertion that every later working document is stored here as a PDF. The current V22–V25 findings are synthesised in the live repository under:

- [results/thermal_diagnostics_v19_to_v24.md](../../../results/thermal_diagnostics_v19_to_v24.md)
- [reports/thermal-management/EXOhSPEC_V25_camera_thermal_homogenisation.md](../../../reports/thermal-management/EXOhSPEC_V25_camera_thermal_homogenisation.md)
- [reports/EXOhSPEC_Master_Thesis_Research_Continuation_2026.md](../../../reports/EXOhSPEC_Master_Thesis_Research_Continuation_2026.md)

This prevents the public storyline from becoming stale simply because a later working report was not part of the original PDF collection.

## Reading rule

This is a historical record, not a flat collection of equally current conclusions. Later calibration or diagnostic work can supersede an earlier interpretation. Website claims should identify whether evidence is **measured**, **demonstrated for a stated interval**, **interpreted**, or **proposed / awaiting validation**.

## Integrity

The original inventory metadata and checksums are retained so the archived evidence remains auditable. Rebuild the inventory with the repository tool after intentionally adding or removing archived PDFs.
