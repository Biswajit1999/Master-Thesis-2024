# EXOhSPEC public gateway

## [Open the EXOhSPEC website →](https://biswajit1999.github.io/EXOhSPEC-website/)

This repository is the public gateway for the EXOhSPEC programme website and the associated MSc research continuation.

The current experimental record, working reports, analysis code, component documentation and unpublished results are maintained in a restricted archive. Approved collaborators can use **Member** on the website to sign in and access the protected research portal.

**Researcher and web developer:** Biswajit Jana

**Supervisors:** Prof Hugh R. A. Jones and Prof William E. Martin

**Institution:** University of Hertfordshire, United Kingdom

Public programme information and published references remain available through the website above.
